# Commander Tool

Magic: The Gathering Commander support tool.

## Features
- Card viewer
- Life / Player counter
- CSV deck support

## Build
- Python 3.11
- PyQt5
- requests

Built and packaged with PyInstaller.

## Usage
For Windows users, download the executable from the Releases page.
Python is not required when using the exe.
